Secure exam mode

A locked-down window for online exams. Set it up here and start it on this PC, or save an exam file to give to students (it holds only a scrambled form of the password).

Exam

Invigilator password

Needed to end the exam early and unlock the PC. Keep it from the students.

What the student gets

  • A full-screen window that stays on top and cannot be closed or minimised; other browser windows are hidden.
  • No tabs, address bar, menu, new windows, developer tools, downloads, printing, or browser shortcuts. Only the exam and the sites you allow open; anything else is blocked and logged.
  • Screenshots and screen-sharing apps see a black window.
  • Switching to another app (Alt+Tab, Windows key) brings the exam straight back and is logged. Windows itself keeps Ctrl+Alt+Del and Win+L; no app can block those.
  • The exam ends when time runs out, or when you press End exam (or Ctrl+Alt+Shift+E) and enter the password. A log is saved and shown.
  • Students can start an exam file by double-clicking it, or from Menu → Secure exam mode → Open an exam file.
