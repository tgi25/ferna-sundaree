Parental controls

Blocks adult sites and turns on SafeSearch, protected by a parent's password. Applies to every window and every profile on this Windows account.

Set up

While parental controls are on

  • Blocked sites show a page with "Ask a parent": the parent's password allows that site once or always.
  • Private windows, Tor windows, developer tools and adding extensions ask for the parent's password.
  • Lists: StevenBlack's hosts lists (adult, gambling, social), updated weekly, plus name patterns for new adult sites.
  • No filter catches everything, and someone with Windows administrator rights can remove any browser filter. For stronger protection also use Microsoft Family Safety on a child's own Windows account.
